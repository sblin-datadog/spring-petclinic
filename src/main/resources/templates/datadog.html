Security

These requests are designed to be detected by Datadog, check Security > App and API Protection, Security > Code Security and Security > Workload Protection.

Threat Management (WAF)

These hit the existing owner search with an attack payload in the query string.

SQL injection attempt XSS attempt Path traversal attempt

Code Security (IAST)

These run user input through a deliberately unsafe sink so IAST flags a vulnerability.


Workload Protection (CWS)

These run a shell command inside the container, which Datadog Workload Protection detects at runtime.
